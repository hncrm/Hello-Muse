# HHX Services — demo website

Demo website for HHX Services: Microsoft Power Apps, Dataverse and Power Platform consultancy for small businesses. Site language: English only.

## Tech stack

- Plain static HTML + CSS — no framework, no build step, no backend, no database.
- Pages: `index.html` (Home), `services.html`, `contact.html`, shared `styles.css`.

## Hosting

This is a static site, so it can be hosted in either place:

- **GitHub Pages** — free, serves directly from this repo's `main` branch. Live URL once enabled: https://hncrm.github.io/Hello-Muse/
- **Azure Static Web Apps** — also serves static HTML/CSS, with a free tier. Deploy from this same repo, or from the same files.

No Azure account is connected to Muse yet, so Azure hosting is not set up in this demo — the files are ready to deploy there.

## Local preview

Open `index.html` in a browser, or serve the folder with any static file server.
